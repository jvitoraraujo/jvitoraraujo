## ✦ About

Information Systems undergraduate at the **Federal University of Ceará (UFC), Quixadá Campus**, seeking a **Backend Developer / Software Engineer (Junior / Entry-level)** position.

My technical work centers on APIs, data modeling and automation with Python 3.12+. I value typed code, versioned migrations, reproducible environments and tools that run locally, without depending on third parties.

Alongside that, I develop original projects that merge engineering and symbolism: book readers, hybrid board games, browser extensions and knowledge bases.
